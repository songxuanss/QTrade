# QTrade 分阶段路线图

## Phase 0：立项与技术验证（约 2-4 周）

### 目标

确定边界，验证高风险假设，形成可执行的一期计划。

### 范围

- 确定第一期目标市场：A 股 / 美股 / 港股 / crypto / 期货中的最小组合。
- 确定数据供应商与授权边界。
- 确定第一个 paper / live broker 或交易所。
- 完成 LEAN 与 NautilusTrader PoC。
- 完成数据样例入库、K 线查询、WebSocket 推送、回测报告原型。
- 完成 SSO 接入 PoC。
- 完成设计系统与核心页面低保真 / 高保真原型。
- 输出数据模型、API contract、OSS 许可证审查。

### 退出标准

- 可以从目标数据源采集至少 3 个月历史数据。
- 可以用同一策略在两个引擎或一个引擎 + 自研示例中跑通回测。
- 可以完成 SSO 登录、登出、本地会话失效。
- 可以在 UI 上看到实时价格与 K 线。
- 明确一期不做事项并获得业务确认。

## Phase 1：专业 MVP（约 8-12 周）

### 目标

交付可信的端到端闭环，支持少量专业用户日常使用。

### 核心范围

1. SSO / OIDC / PKCE / 权限 / 审计。
2. Instrument master、历史行情、实时行情、数据质量。
3. 专业工作台、K 线、自选列表、基础指标、布局保存。
4. 行情、风险、数据、系统四类告警。
5. 策略项目、版本、模板、参数与安全校验。
6. 事件驱动回测、绩效报告、实验对比。
7. Paper trading 完整链路。
8. 单一市场 / 单一账户受控实盘试点。
9. 预交易风控、kill switch、对账、审计。
10. 管理台、监控、备份、CI/CD。

### 一期增强项

如果时间允许，按优先级加入：

- Walk-forward 回测报告。
- Telegram / Slack 告警。
- 回测结果 PDF / HTML 导出。
- 策略参数网格扫描。
- 基础组合视角暴露与集中度分析。
- API key 测试网连接诊断。

### 退出标准

- 5-10 个真实用户连续使用 2 周。
- 每日自动采集任务成功率 > 99%。
- 核心行情查询 p95 < 500ms。
- 回测重复运行结果完全一致。
- 纸面交易订单生命周期无状态丢失。
- 实盘试点通过风控、审批、对账、kill switch 演练。
- P0 安全项全部关闭。

## Phase 2：团队生产化与研究深化（约 3-6 个月）

### 目标

从个人工具升级为团队研究平台。

### 范围

- 多市场、多数据源、多账户。
- Tick / order book 历史数据与重放。
- ClickHouse 或 TimescaleDB 性能升级。
- 更完整的数据目录、数据血缘、权限控制。
- JupyterHub 研究环境。
- 因子库、指标库、信号回测。
- 参数优化、Walk-forward、Monte Carlo、过拟合诊断。
- 策略审批流与团队协作。
- 多策略组合回测与资金分配。
- 更丰富的告警规则和值班处理。
- 公开 API / Python SDK。
- 移动端推送与只看视图。

### 退出标准

- 支持至少两个资产类别与两个执行通道。
- 回测任务可横向扩展，支持上千个参数组合。
- 策略从研究到实盘有完整审批链。
- 多账户对账成功率达到业务要求。
- 数据目录可追溯所有实验输入。

## Phase 3：机构级风险与高可用（约 6-12 个月）

### 目标

面向真实资金规模和团队治理，提升稳定性、风险与合规能力。

### 范围

- 分布式任务调度与多区域部署。
- 服务高可用、故障转移、灾备演练。
- 热备执行节点与主备切换。
- 更完整风险模型：VaR / CVaR、压力测试、情景分析、流动性风险。
- 归因分析：行业、因子、币种、策略、执行来源。
- TCA：成交质量、滑点、延迟、市场影响。
- 执行算法：TWAP、VWAP、Iceberg、参与率。
- 高级订单：OCO、OTO、冰山、止损止盈组合。
- 合规报表、交易日志留存、异常交易审查。
- 审批与职责分离。
- 供应商故障降级。

### 退出标准

- 关键服务达到目标 SLO。
- 可执行完整灾备与主备切换演练。
- 风控系统能在异常场景下先拒单再告警。
- 机构级日报、月报、审计导出可用。

## Phase 4：智能研究与自动化（约 12-18 个月）

### 目标

让研究效率与自动化程度接近国际一流平台。

### 范围

- ML pipeline：特征库、训练、验证、模型注册。
- MLOps：数据漂移、模型监控、自动重训、回滚。
- LLM 研究助手：策略解释、代码审查、数据质量诊断、报告生成。
- 自动实验编排：想法生成 -> 回测 -> 稳健性检验 -> 人工审核。
- 市场状态识别与策略切换。
- 另类数据接入：新闻、情绪、链上、宏观数据。
- 策略组合优化与动态资金配置。
- 更智能的异常交易检测。

### 退出标准

- 研究流程可重复、可比、可审计。
- 模型版本、训练数据、指标和部署状态完整可追溯。
- AI 建议始终有人工审核边界，不绕过风控。

## Phase 5：平台生态与商业化（约 18-24 个月以上）

### 目标

将 QTrade 从内部平台扩展为可商业化的多租户平台。

### 范围

- 多租户 SaaS 架构与隔离。
- 订阅、计费、配额、 marketplace。
- 团队协作、评论、权限模板、组织策略。
- 数据与策略市场。
- 白标和私有化交付。
- 企业 SSO / SCIM / 审计合规包。
- 插件体系和第三方 connector 认证。
- 社区模板与公开竞赛。

### 退出标准

- 具备独立交付、升级、监控和支持流程。
- 商业许可证、数据许可证、监管边界清晰。
- 插件 API 稳定并有兼容性测试。

## 里程碑建议

| --- | --- |

| 第 3-4 个月 | Phase 1 Beta：告警、风控、受控实盘试点、审计 |
| 第 4-5 个月 | Phase 1 GA：稳定运行与备份恢复演练 |
| 第 6-9 个月 | Phase 2：多市场、团队研究、组合回测 |
| 第 10-14 个月 | Phase 3：机构级风险、高可用、TCA |
| 第 15-20 个月 | Phase 4：智能研究与 MLOps |
| 第 21 个月起 | Phase 5：多租户与商业化 |
