# 采用本地 CodeGraph 索引作为开发期检索工具

QTrade 允许开发者与编码代理使用 CodeGraph（`.codegraph/` 下的本地 SQLite 结构索引）快速定位符号、定义与调用边，减少逐文件 grep 与阅读的往返。索引在本地由 `codegraph init` 生成，随文件监听增量更新；索引目录属于机器相关的可重建产物，已按 `.codegraph-wsl/.gitignore` 的同样约定排除在提交之外，也不进入 CI、镜像构建或运行时依赖。

选择“本地、可选、只读检索”而不是把索引产物入库、引入托管代码索引服务，或让代理绕过源码直接信任索引：前者零运维、无外部服务与凭据，不改变现有依赖策略；后者避免把检索结果当成正确性证据。检索只作为阅读入口，正确性仍由类型检查、pytest、`scripts/check_architecture.py`、迁移集成测试与真实栈验收裁决。代价是每位开发者需自行初始化索引、写入后约有 1 秒同步延迟，且跨文件解析是尽力匹配；未索引的仓库（没有 `.codegraph/`）直接退回常规工具。代理使用规则见仓库根目录 `AGENTS.md`。
