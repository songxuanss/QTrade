# QTrade 专业 UI / UX 蓝图

## 1. 设计原则

1. **信息密度优先**：专业交易界面应一屏呈现多维度状态，而不是大量营销式留白。
2. **速度即体验**：行情、订单、告警必须低延迟；慢路径使用骨架屏和渐进加载。
3. **键盘友好**：支持命令面板、快捷下单、切换标的、切换周期、保存布局。
4. **状态透明**：数据延迟、供应商故障、回测进度、实盘暂停必须显式可见。
5. **风险醒目**：风控拦截、回撤、连接异常使用强视觉信号，不允许被普通信息淹没。
6. **可恢复工作区**：用户布局、筛选、图表配置、列配置可保存和共享。
7. **国际化与可访问性**：中英文、暗色/亮色、键盘可达、色彩不只依赖红绿。

## 3. 一期核心页面

### 3.1 全局工作台

内容：

- 账户权益与当日盈亏。
- 全局风险状态。
- 活跃策略与订单状态。
- 数据源健康。
- 未处理告警。
- 自选市场快照。
- 系统任务状态。

交互：

- `Cmd/Ctrl + K` 命令面板。
- 快速跳转策略、标的、订单、告警。
- 支持用户自定义卡片布局。

### 3.2 图表终端

内容：

- K 线、成交量、指标面板。
- 订单、成交、持仓、策略信号叠加。
- 时间周期切换、跨周期对比。
- 价格警报创建。
- 数据质量提示。

交互：

- 十字光标、量测工具、缩放、导出图片。
- 快捷键切换周期、切换标的、添加指标。
- 支持多面板布局。

### 3.3 策略编辑器

内容：

- 代码编辑器：Monaco Editor。
- 参数 schema 表单。
- 依赖与环境锁定。
- 静态检查结果。
- 版本 diff。
- 发布状态流。

交互：

- 提交前必须显示变更摘要。
- 运行回测前显示数据范围与预估成本。
- 禁止把未通过校验的策略发布到实盘。

### 3.4 回测报告

内容：

- 核心指标卡片：收益、年化、波动、Sharpe、最大回撤、换手率。
- 权益曲线、回撤曲线、滚动收益、月度热力图。
- 交易分布、持仓周期、盈亏分布。
- 与基准对比。
- 参数敏感性与多实验对比。
- 数据版本、代码版本、引擎版本。

交互：

- 指标可解释：悬浮展示公式与样本数。
- 交易表与图表双向联动。
- 支持导出 HTML / PDF / CSV。

### 3.5 实盘控制台

内容：

- 账户连接状态。
- 策略运行状态。
- 当前订单、持仓、暴露、现金。
- 风控限额使用率。
- 最近成交和拒绝原因。
- kill switch 与暂停策略。

交互：

- 实盘操作必须二次确认。
- 风控拒绝原因显式展示。
- 断线时明确区分“本地连接断开”和“交易所状态异常”。

### 3.6 告警中心

内容：

- 告警分级：critical、high、medium、low、info。
- 来源、规则、主体、时间、状态、负责人。
- 告警详情与上下文快照。
- 处置记录。

交互：

- 支持批量确认、静默、认领。
- 相同根因自动合并。
- 可从告警跳转到图表、订单、日志或数据任务。

## 4. 设计系统基线

| 类别 | 建议 |
| --- | --- |
| 主题 | 暗色默认，支持亮色 |
| 色彩 | 涨跌可按市场习惯配置；危险状态必须高对比 |
| 字体 | UI 使用 Inter / system-ui；数字使用 tabular-nums |
| 网格 | 8px spacing，信息表格支持紧凑模式 |
| 表格 | 固定列、列保存、虚拟滚动、CSV 导出 |
| 图表 | Lightweight Charts 处理价格轴；ECharts 处理统计图 |
| 反馈 | skeleton、空态、错误态、重试、部分失败提示 |
| 权限 | 隐藏 + 后端强制校验；无权限显示可申请 |
| 帮助 | 内置术语、公式、风险提示 |

## 5. 与国际主流系统竞争的关键体验

| 竞品能力 | QTrade 一期对标 |
| --- | --- |
| TradingView 图表体验 | 专业 K 线、指标、叠加、警报 |
| QuantConnect 研究流 | 策略项目、回测、报告、实验对比 |
| Bloomberg / Trading Terminal 信息密度 | 多面板、快捷键、市场监控、告警 |
| Binance / OKX 交易台 | 账户、订单、持仓、深度、实时状态 |
| Wind / FactSet 数据体验 | 数据目录、血缘、质量报告、导出 |
| Institutional risk tools | 限额、暴露、回撤、审计、kill switch |

一期 UI 竞争力不来自复制全部功能，而来自：**速度、密度、可信状态、清晰异常、可复现研究和受控实盘**。
