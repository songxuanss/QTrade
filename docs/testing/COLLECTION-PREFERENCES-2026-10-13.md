# 工作台选择持久化阶段

对应 OpenSpec `complete-professional-data-workbench` 6.1 的部分实现；完整默认时间规则和全部 UI 用例仍未完成，不勾选整项。

选择属于 QTrade 工作台偏好，独立 collector 不存储浏览器草稿。新增严格 `CollectionPreferences` v1，保存类别、来源、周期、两日期、原标的输入、池快照 ID、明确因子选择和下载模式；不接受用户/工作空间 ID 或凭证字段。日期可部分填写以保留草稿，执行计划仍独立验证完整范围。无任务身份、预览覆盖版本或秘密进入偏好。

追加业务库迁移 0037，复合主键 `(user_id, workspace_id)`、成员外键、版本检查；不修改旧迁移或 collector 数据库。GET/PUT 桥接从当前身份推导归属，READ 读取、DATA_MANAGE+CSRF 写入；持久适配器再次检查当前成员/角色，写入与成员变更通过 workspace 行锁串行。读取非法持久草稿返回安全不可用错误，不输出原内容。

页面“保存选择”将当前输入写入真实业务库，SSR 在刷新及重新打开时恢复。保存是显式操作，未保存修改不声称已持久化。恢复不可用来源或不支持周期时保留选择、显示限制且不能执行，不自动改用目录第一来源。列表中缺少已保存池时保留 ID 并提示确认可用性；提交仍由服务端验证作用域和冻结成员。偏好读取失败明确提示当前默认输入及重试动作。
