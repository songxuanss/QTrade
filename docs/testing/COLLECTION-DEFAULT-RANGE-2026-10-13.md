# 默认日期计算阶段验证

日期：2026-10-13。对应 `complete-professional-data-workbench` 6.1、7.2 的计算基础，**不是部署或完整任务验收**；两个任务继续未勾选。

新增独立核心 `natural_year_range`：输入明确市场时区、供应商交易日历、发布时间和依据，选择最近按发布时间应可获取的交易日，生成最近自然年半开范围。结束为该交易日之后的当地零点，开始为结束减一个日历年；闰日不能在上一年表达时夹到二月最后一天。不读取本地覆盖或本地最后一条数据，不将发布时间估计当成已实际发布。

MaiRui 日线适配器使用官方历史接口说明中的预计 17:10 完成时间，依据 https://www.mairuiapi.com/hsdata 。当本年尚无符合发布时间的交易日时，仅追加请求上一年来源日历；日历无效、空或不可用时明确失败，不退化为工作日猜测。当前年有效日历缓存复用。因子和分钟暂不支持此默认计算入口，避免借用日线规则冒充其发布证据。

## 自动默认与一年日线阶段

预览时先验证标的/池范围和周期；两日期均空则查询来源默认日期，两日期只填一个时拒绝并保留输入。计算或预览期间改变选择会丢弃过期响应。默认发布时间未验证的因子/分钟明确提示填写自定义日期，不借用日线规则。
