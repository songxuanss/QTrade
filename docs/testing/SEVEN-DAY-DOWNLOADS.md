超过七天的新建下载会按连续半开区间拆分，每段最多七天，最后一段保留原结束。
整体下载上限仍默认不限；分段不是恢复七天总上限。日线、分钟线和 Tick 的 API
提交均使用该流程。子任务有公共分组标识、稳定子任务身份、独立范围、状态、
checkpoint、重试及提交审计。创建同组子任务使用同一 PostgreSQL 事务；后段身份
冲突会回滚前段创建。已有任务与已下载批次保持不可变，不原地拆改旧请求。
“仅下载缺失数据”只拆分缺失区间，保留已完成数据。
