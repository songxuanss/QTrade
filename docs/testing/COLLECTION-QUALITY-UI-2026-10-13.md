# 质量报告工作台阶段

已接入已实现的 scoped job/part 质量接口。每个分段按需加载报告，避免股票池页面发起每分段的自动查询；显示规则、报告版本、检查时间、数量、状态和中文问题说明。通过、警告、阻断、无观测分别表达；空报告明确未检查，旧产物不能自动升级为通过。异常读取有可重试提示，报告不代表完整研究或回测就绪。

当前 scope/job/part 链接由真实 PG 验证；核心额外验证持久适配器返回的 scope/part，防止损坏元数据导致访问其他目录。原始 job/actor 可能因复用已完成分段而不同，不错误拒绝同空间合法读取。受控损坏边界测试证明不打开外部 archive。

部署检查发现并修复主干 UI 故障：并发请求先等待全部响应，再读取正文；慢因子目录请求约 10 秒后返回503，快目录/任务响应的读取 deadline 已到，触发 Body already read / terminated，使页面整体进入错误页。现在各请求及时解析正文，局部失败有独立结果；响应 stream 给每个消费者独立副本。两个单元测试分别覆盖共享响应读取、快响应在慢失败到来前的取消期限。不能把因子目录503解释为已无历史或账户权限被拒绝。
