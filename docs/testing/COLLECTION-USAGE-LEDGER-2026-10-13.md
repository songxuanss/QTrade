# 用量预留账本基础阶段

## 领域与持久接口

供应商无关的UsagePolicy/UsageRequest/UsageLease/UsageResult及UsageLedger.reserve/finish，把预留、策略日、完成和拒绝表达为独立接口。PG实现使用自己的连接模块，不借用任务仓储实现；来源/操作仅保存安全标识，未包含URL、请求参数、凭证或供应商正文。信用是运维防护单位，不是已验证供应商账单。

新增0008_usage_ledger.sql，追加usage_day与usage_request。请求身份及来源事务锁序固定，检查来源/作用域信用与有效预留后原子扣账；不增加预览任务或修改旧发布。相同身份重复返回旧记录，不重复扣账，也不让第二调用者取得新的出站许可。冲突身份/不同结果拒绝。完成可重试同一token和冻结结果；过期或冒用所有权拒绝。

来源时区定义日边界；跨天不会释放仍有效的上一日并发预留。失败/过期保留信用，防止无法确认的外部效果被退款。无scope仅限metadata.*；采集/研究缺scope立即拒绝。SQL拒绝NULL版本、NULL完成结果和逆序完成时间。
