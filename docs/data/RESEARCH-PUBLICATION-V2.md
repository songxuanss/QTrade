# 研究质量发布与冻结查询

本阶段提供研究类别门禁/发布/分页查询，真实供应商接入、Worker完整生命周期和UI消费仍未完成。受控PIT证据不计MaiRui PIT可用。

## 发布规则与状态

`research-quality.v1` 固定绑定产物、标准记录摘要、规则版本及问题列表，结果为 passed/warning/blocked。发布前重验原始及标准字节/内容/数量、冻结计划与分页链，检查类别日期范围、重复、身份及可知时刻；阻断保留原始与标准证据，没有发布引用。

- 格式由明确契约验证；归档不一致、范围错误、重复标准记录、分页缺页/循环/未连通页、错误身份、未来可知时刻及不支持日期轴阻断。
- 普通财务未知单位、期间或历史可知时间是明确警告，保留原值且不暗中换算；稀疏财务不套行情每日完整性规则。
- 成员同生效日修订保留版本；不同起始日有效区间重叠阻断并要求澄清，不暗中合并。
- 当前事件规则的 event_date 按公告日期核验，公告日未知阻断；现金支付日未知带现金核算限制。其他事件日期筛选口径需要明确新规则版本，不能静默用另一日期。
- 复权因子保留基准/算法及研究前提警告，不能据采集完成自动认证完整复权体系。

这些是研究类别规则。旧v1行情/因子发布门禁仍待完整改造，本阶段不宣称整个采集发布门禁交付。

## 持久发布

新增迁移0005保存 append-only quality/publication，数据库触发器检查已存储的质量结果非blocked、摘要绑定正确且公开清单与实际标准产物/质量记录一致。不能用另一个产物的检查结果发布当前产物。质量重新检查冻结首次相同结果时刻；发现新阻断问题形成另一检查身份。修复转换后标准产物与发布引用为新版本，旧阻断/发布不改写。

迁移0006追加加固缺字段/JSON null检查，拒绝不完整清单、错误schema、无效质量状态和伪造问题列表，避免SQL三值逻辑绕过；0005保持原已部署摘要不变。

ResearchReleaseService每次检查与发布重新校验当前manage授权，实际发布前再次验证归档。发布ID绑定标准产物及质量身份，重复发布返回原清单；清单内容版本摘要包含规范化字段/时间，重试不制造新引用。发布时间规范JSON格式防止序列化摘要不一致。

## 公开消费

GET `/v2/research/publications/{publication_id}` 返回仅已发布清单、原始血缘和质量问题；POST `/v2/research/query` 要求明确产物、内容版本、类别与分页cursor。主体/作用域沿用独立采集身份回查。错版本409，跨作用域403，不存在/未发布404；原始或标准归档受损时记录查询拒绝，不以旧状态放行数据。

cursor绑定作用域、产物、内容版本、类别和as_of条件，不能从另一版本或时点复用。分页返回页摘要。普通历史capability.supports_as_of为false时明确unsupported；仅完整可知证据能力才允许按时点查询。允许时只选已证据化且当时可知的版本，再按逻辑记录键选择最新可知版本；未知时间被排除，冲突相同可知时刻拒绝，不随意选一个。

逻辑键分别为财务来源/标的/报表/报告期、成员池/生效日、身份变动/生效日、稳定事件身份，以及复权观测日/口径/基准。不同清单冻结引用各自保留，后续修订不改历史清单。
