# 已授权数据能力探查与接入审计

探查日期：2026-10-12。总体目标仍在实施，本文不是完整研究数据或供应商可靠性认证。私有证书来自现有 `.env`，没有购买、登录新数据厂商账号或追加因子包。

## 方法和证据

官方文档：[行情/财务/公告/F10](https://www.mairuiapi.com/hsdata)、[指数](https://www.mairuiapi.com/hszsdata)、[因子](https://www.mairuiapi.com/factordata)、[Quant Pro 权益](https://mairui.club/packs)。文档网页由本机 HTTP 读取并保存到 Git 忽略目录；浏览检索工具对 hsdata/hszsdata 超时，本机实际 HTTP 200。官方 SDK 文档与网页因子目录数量存在 68/85 等差异，不能只采用 SDK 文档宣称。

`scripts/probe-data-capabilities.py` 使用当前证书做有界只读探查，约每 6 秒一个请求。公开摘要：[PROVIDER-PROBES-2026-10-12.json](PROVIDER-PROBES-2026-10-12.json)，包含去秘密接口模板、请求范围、HTTP/供应商状态、数量、实际字段及脱敏样本摘要。真实样本位于 `.tools/data-probe/*-sample.json`（0600、Git 忽略）；不是业务归档或端到端证据。错误响应不计为证券数据。因子 `roe` 初始试探未匹配目录 ID，返回空；复核实际目录后正确 ID `roe_ttm` 返回 5 点，不能把前者解释为无历史权限。

## 时间与字段字典

- 行情 `t`：来源北京时间；分钟是区间结束标签，标准输出区间开始，日线另行按日期解释。`v` 手转换为股，`a` 元；调整价格与未复权成交量额必须分开，不把调整后价格用于量额校验。
- 因子 `trade_date`：观测交易日。`value` 保留精确值/信号/空值。原始计算版本、更新时刻、报告期、可知时间未知时保持 unknown；文档定义有独立证据来源，不能覆盖供应商缺失字段。
- 财务 `jzrq`：报告截止日；`plrq`：来源披露日期，date 精度。采集时间只表示本地看到记录的时间，不能补造历史可知时间。单位、合并/母公司、累计/单季、修订身份须分别记录，不把季度截止日等同于单季值。
- 分红 `sdate/cdate/edate/hdate`：各自公告/除权/登记/上市日期，`--` 为未知。`send` 元/10股，`give/change` 股/10股。支付日缺失不得由除权日替代；稳定事件身份与内容版本分开。
- 当前成员观察时间：本地取得快照的时间，没有历史有效区间。退市/改名/历史成员及复权因子能力保持未确认，不提供虚构查询结果。

## 第二轮复核与范围决策

### 第二轮有界语义复核

同日未复权与前复权价格对照已取得：600519.SH 在 2015-09-01、02、07 的未复权收盘分别为 194.37、194.61、188.71，而当前供应商前复权收盘为 -103.46、-103.22、-109.12。官方因子说明使用前复权日线价格，因此早年 PE 为负有相应价格语义证据，不能仅凭负值断言上游接口故障。未取得算法版本、调整基准及完整因子链，仍不能认证历史 PE 可直接用于研究，也不能将这类价格当实际成交价格。原始价格的正值规则不能直接泛化到供应商前复权价格；口径警告必须显式保留。

2015 年利润表的完整六行有界响应均按报告截止日落在请求年份，披露日期可在次年甚至更晚。同一 `2015-06-30` 报告期分别有 `2015-08-28` 和 `2016-08-27` 披露记录，EPS 为 6.91 和 6.28；`2015-03-31` 分别有 `2015-04-21` 和 `2016-04-21` 披露，EPS 为 3.82 和 3.47。故不应按报告期直接去重或仅保留第一行。响应证明存在多披露版本，但不证明版本账本完整、精确历史可知时间或更晚版本的具体重述原因。期间收入呈年内累计特征，单位和累计口径仍需来源证据；普通历史接入保留原单位未知及期间语义证据，不暗中做单季差分。

`north_holding_ratio` 最新截面非空，但 2025-09-01～05 历史请求 HTTP 200 返回零条。结论仅为该历史样本无观测，不等于无权限、所有日期无历史或最新能力未开放。UI 和适配器应分别记录最新/历史状态，不能继续使用“全部北向未开放”的统一断言。

分红完整 31 行样本中有 8 行送股或转增为正，确认有限送转模型并非仅凭零值字段猜测。分红日期与每十股单位沿用官方说明，未提供的现金支付日、配股和拆并股账本仍保持未知。完整有界样本通过摘要命名保存，旧样本未改写；公开摘要已合并本轮记录。

本次有界复核后已固定 [接入及验收清单](COLLECTION-ACCEPTANCE-SCOPE.md)。范围包括核心行情、所选历史因子、已验证的普通财务/分红语义及未确认类别的扩展契约；单位未确认、PIT/成员/退市/复权因子证据不足须有明确限制和拒绝，不得在后续因外部失败删掉已固定必接入项。

所有类别都要继续经 UI→真实 API/DB/Worker→非空归档→质量门禁→发布→消费者→刷新验收；本表中的 sample 不能据此升级 E2E。商业研究主源仍未配置其他账号，不能给出未经实测的可靠性冠军。
