# 数据采集工作台

入口：主导航“数据管理”，当前验证部署为`http://127.0.0.1:13000/workspace/data`。页面按工作内容分区，每次展示一个区域；手机上可横向滑动分区栏，当前选中项会自动进入可见范围。

| 分区 | 用途 |
| --- | --- |
| 行情与因子 | 设置标的、来源、周期和日期，预览计划，执行并追踪归档/发布结果 |
| 板块与股票池 | 查找板块、查看成员、保存冻结快照并批量下载 |
| 财务与事件 | 二级切换财务三表或分红送转，查看任务与具体发布版本 |
| 自动更新 | 创建、启停和检查已保存的更新计划 |
| 数据资产 | 分别浏览研究数据集、原始批次、质量问题和兼容采集任务 |
| 运行监控 | 分别读取新鲜度、用量/配额及来源能力证据 |
| 逐笔与兼容 | 使用原有逐笔归档及兼容下载入口，保留既有范围限制说明 |

## 常用流程

1. 进入“行情与因子”，明确标的与数据类型，设置日期、周期和补缺/重采方式；查看预览后提交。状态以Worker实际执行、归档、质量及发布结果为准，排队不等于成功。
2. 批量任务先到“板块与股票池”查看或保存成员，再下载全部成员；该入口与单股工作台各自的选择范围保持独立。
3. 到“财务与事件”选择报表或事件类型，按页面标明的日期语义采集并浏览发布版本。普通财务和有限事件仍保留PIT/单位/完整性限制。
4. 检查问题时进入“运行监控”；长记录和证据在区域内滚动，页码、刷新和操作按钮保留在相应工具内。来源说明是核对截至日的证据，不能代替当前授权或健康证明。

切换分区保留当前页面内尚未提交的表单。刷新/重开恢复URL中的导航位置；输入持久化仍使用原有“保存选择”等入口，**不承诺未保存草稿刷新后保留**。顶端“刷新数据”刷新当前分区，不回到默认首页。键盘可用左右箭头、Home/End切换标签，再用Tab进入内容；记录滚动区也能获得键盘焦点。

## 可直接打开的分区

- 财务报表：`/workspace/data?data_view=fundamentals&research_view=financial`
- 分红送转：`/workspace/data?data_view=fundamentals&research_view=events`
- 股票池：`/workspace/data?data_view=pools`
- 自动更新：`/workspace/data?data_view=schedules`
- 来源说明：`/workspace/data?data_view=monitor&monitor_view=sources`
- 数据新鲜度：`/workspace/data?data_view=monitor&monitor_view=health`
- 原始批次：`/workspace/data?data_view=assets&asset_view=raw`

旧的股票池、财务/事件、原始批次等片段链接仍会打开所属区域。无效分区键安全回到默认采集区；股票池空搜索仍留在股票池。未登录的分区链接经SSO返回相应导航位置，登录失败仍需重新登录，不绕过原权限。

## 归档重处理

财务/事件任务的“RAW 重处理”打开独立弹窗：先预览完整RAW、转换版本和上限，再确认创建新任务。该操作不重新访问供应商，关闭弹窗不会取消已提交任务；可刷新处理结果，发布后从新任务浏览。失败提示按缺页、摘要、兼容转换、上限或当前权限分别处理。只有HTTP回执不能重处理，也不会因此补造PIT能力。

只读成员可以浏览已发布版本及保存的重处理血缘；查询以当前查看者身份执行，原任务创建者只是血缘信息。刷新任务和重新打开后，新旧发布均保留。提交超时应沿用同一预览重试，明确重新预览会产生另一候选身份。

确认重处理后可复制弹窗的新任务编号，在“搜索财务近期任务”或“搜索公司行为近期任务”中定位该任务，再浏览对应版本；不要把原任务的既有发布当作新处理结果。

## 紧凑采集工作区

“行情与因子”内分为“新建采集”和“任务与结果”：新建视图只显示配置与计划预览，提交后自动进入结果视图。结果页上方选择已保存任务，下方检查进度、质量和发布记录；切回新建仍保留本页未提交的输入。只读成员直接查看任务结果。

分段和数据表在各自区域内滚动，刷新、重试、取消及分页仍在区域外。表格超过一页时使用“下一页记录”，没有截掉后续数据。Tab可进入滚动区域，PageDown可滚动；手机页面不需要横向拖动整页。刷新恢复当前视图和已保存任务，未保存输入仍不承诺刷新保留。

行情／因子分段也可通过“离线重处理”选择已保存的完整转换输入，预览后确认新任务，再点击“查看新任务与发布”。这不会重新下载来源或覆盖旧版本，来源调用为0；适合已保存输入的转换修复和规则复核，不适合补采新行情。原获取时刻和未知可知时间保持，新发布时间不表示来源已更新。无完整检查点的旧任务会提示不可重处理；只读成员可查看输入与血缘。
