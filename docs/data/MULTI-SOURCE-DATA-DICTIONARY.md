# A股数据类目、字段与主源选择

评估日期：2026-10-10。以下是字段设计与选源判断，不是已上线数据目录；字段存在、
账户有权限、样本返回、真实端到端完成是四种不同证据。新正式版MaiRui证书已保存在
项目根目录私有`.env`，API/Worker已确认加载；凭证值不进入本文、Git和测试报告。

## 选源判断

当前不宜把MaiRui设为唯一量化研究主源。依据是现有实际逐笔历史很短、旧证书下
批量429/目录503，以及历史交易状态、复权和财务PIT尚未验收；不是依据公司成立时间，
也不能推断其全部数据都少。官方[公告](https://www.mairuiapi.com/news/)明确历史逐笔
自2026-08-13归档，并宣称Pro完整历史分钟线最长约1991年，本年度按月更新。
不同接口、股票和套餐必须分别验收，正式版不自动等于Pro，旧证书配额结论不能
当作新证书实测结果。

若以完整量化研究能力优先，**RQData是商业主源优先候选**：依据是
[历史行情与合约接口](https://www.ricequant.com/doc/rqdata/python/generic-api)、
[复权/公司行为与显式PIT财务](https://www.ricequant.com/doc/rqdata/python/stock-mod)
和独立部署接入方式。该判断是工程选择，不是实测可靠性排名，没有该账号就不能
宣布已接通。其Tick示例含累计量额与盘口，是行情快照；不能冒充每笔成交或L2委托。

若低成本和日频优先，**Tushare Pro是日频主源候选**，用
[原始日线](https://tushare.pro/document/2?doc_id=27)、
[复权因子](https://tushare.pro/document/2?doc_id=28)及财务/历史状态补齐研究基础。
其[权限表](https://tushare.pro/document/2?doc_id=290)区分积分与独立权限，分钟不是
普通积分自动包含的能力。没有积分/账号样本不承诺免费完整数据或多年完整逐笔。

| 来源 | 合适用途 | 当前证据与不足 | 接入定位 |
| --- | --- | --- | --- |
| MaiRui | 日/分钟行情及现有成员目录、近期成交列表 | 项目已完成真实日线/5分钟和近期逐笔链路；正式版权限重新验收；PIT/完整L2未证明 | 保留并复核正式版，不因一个逐笔接口短历史否定全部行情 |
| RQData | 日/分钟、复权、公司行为、历史合约、PIT财务及行情快照 | 官方接口契合量化需求；订阅、沪深京范围、起止、吞吐、修订与可用性未实测 | 商业研究主源优先候选，先小样本和连续运行验收 |
| JQData | 行情、参考/基本面，已有聚宽研究体系 | [官方SDK](https://github.com/JoinQuant/jqdatasdk)支持外部调用，账号与具体历史权限未验证 | 商业备选，对照同一验收集，不凭宣传选胜者 |
| Tushare Pro | 日频、复权、估值、财务与历史参考资料 | 文档类别丰富；积分/独立权限，公告字段不自动形成项目PIT查询 | 低成本日频候选/对账源 |
| BaoStock | 免费历史K线、复权研究和对账 | [官方平台](https://www.baostock.com/)提供相关接口；本项目可用性、市场覆盖与限制未验证 | 免费补充，不承诺唯一主源或完整逐笔 |
| AKShare | 特定公开数据采集/交叉核验 | 采集库不是统一供应商；各上游的授权、覆盖、变更和稳定性须单独验收 | 补充工具，来源名须写实际上游，不统一标作权威数据库 |
| 授权交易所/行情商L2 | 成交/委托/撤单序列、微观结构 | 须验证指定产品和时间；产品变更可能影响历史字段，不能认为所有L2都包含所需逐笔 | 订单流/队列策略另行采购验收，当前不购买 |

## 公共字段与语义

每一类都需要`instrument_id`（非证券类使用实体/市场ID）、`provider_id`、
`source_dataset`、`source_record_id`（无则明确）、`schema_version`、`mapping_version`、
`source_observed_at`、`captured_at`、`revision_id`、`raw_batch_id`和质量状态。
需要历史可见性的记录还必须声明`published_at`/`available_at`及其证据和时间精度。
未提供精确发布时间不能从报告期推导；只有公告日期时明确date精度并采用保守可用
规则，不能制造秒级PIT真实性。原值、原单位、原时区和缺失原因必须保留。

标准证券数量为股、金额为元并带币种，精确值按Decimal/十进制文本；财务万元/亿元、
成交手/股、千元额、百分比/小数由来源映射显式转换。未知不填0，负值是否允许按字段
定义；日期不是时间戳。日线有交易日期，分钟有UTC半开区间和原始标签开/收时间说明。
证券类型、交易所与标识同时确定身份，股票000001.SZ与指数000001.SH不得冲突。

## 下载类目与最小字段

| 优先级 / 类目 | 必需核心字段 | 验收重点与用途 |
| --- | --- | --- |
| P0 证券主数据/历史身份 | instrument_id、source_code、名称、asset_type、exchange、board、currency、上市/退市日期、代码有效期、最小价位、历史交易单位/规则 | 包含退市及改代码，复现历史证券池；当前Instrument不冒充历史状态 |
| P0 交易日历/时段 | exchange、trade_date、is_open、session_type、open_at/close_at、临时时段修订 | 界定应有日期/区间；不能用已返回行情日期反推完整日历 |
| P0 交易状态/限制 | trade_date或有效区间、停复牌、ST类别、涨/跌停价、上市阶段、规则版本 | 可交易性、缺档与停牌分开；历史10%/20%等规则不能硬编码成全市场统一值 |
| P0 原始日线 | trade_date、open/high/low/close、volume、turnover、原始pre_close及口径、is_final、session范围 | 未复权是原始基线；价合法、量额单位、停牌与缺失；盘后固定价是否包含须声明 |
| P0 复权/公司行为 | effective_date、factor及方向/公式/基准日、现金分红每股与税口径、送转比例、配股价/比例、登记/除权/支付日、公告及修订 | 日线与因子/事件分开保存；计算收益与现金/持仓变化，不直接拿前复权价模拟真实成交 |
| P0 历史行业/指数 | 分类体系/版本、pool_id、member_id、有效起止、成分权重及其日期、公告/可用时点 | 当前成员不回填过去；指数行情与成分股行情分开，权重缺失不假定等权 |
| P0 基准/指数日线 | index_id、trade_date、OHLC、指数类型与价格/全收益口径、基期与版本；量额仅有来源定义时保留 | 指数点位不是可成交股票价格；指数收益口径与组合一致 |
| P1 估值/股本 | trade_date、总/流通/自由流通股本与市值、PE及TTM/LF定义、PB、PS、换手率及分母、收益率口径 | 缺失/负PE分开；来源股本时点与价格对应，不混市值单位 |
| P1 财务PIT（基本面策略P0） | issuer_id、report_period、statement_type、metric_code/value、currency/unit、合并/母公司、累计/单季、公告/可用时间、修订及原公告引用 | 三表：收入/利润/归母、资产/负债/权益、经营/投资/融资现金流；当时不可知记录不能入历史回测 |
| P1 原始分钟Bar | interval_start/end、granularity、OHLC、volume/turnover增量、完整Bar标记、session、时间标签口径 | 空区间/停牌/源缺失不强行填价；由原始分钟派生更粗周期要保存输入与算法 |
| P1 行情快照 | exchange_ts、receive_ts、last、累计volume/turnover、bid/ask价格/数量各档、涨跌停价、快照频率/序列（若提供） | 日内累计量差分需处理日切/修正；无序列就不声称快照无丢失 |
| P2 成交逐笔（高频P0） | exchange_ts及精度、trade_id/sequence、price、volume、turnover、trade_type、买卖方向及推导说明、买/卖委托引用（若提供） | 无序列无法证明全逐笔；成交列表中的推断主动买卖不当作交易所事实 |
| P2 委托/撤单逐笔（队列P0） | exchange_ts、channel/sequence、order_id、event_type、side、price、数量、关联撤单/成交ID | 产品及交易所规则不同；重建、乱序和缺序检测，不用行情快照替代 |
| P2 公告/事件/另类 | event_id、event_type、issuer_id、occurred_at、published/available_at、原文引用/哈希、修订、来源分类版本 | 预告、融资融券、龙虎榜、资金流/宏观分别建schema；供应商估算不是交易所逐笔事实 |

P0是日频研究基础；P1/P2按具体策略升降级。账户、委托、成交和可卖量由交易上下文
及Broker回报拥有，不作为历史行情供应商数据混入本目录。类目字典定义完整目标，
**不是承诺首轮实现全部类别**。现有项目已发布的仍是未复权Bar和近期原始逐笔。

## 最小选源验收集

1. 沪深京分别取样，含老股票、新股、ST、退市、停牌、分红送转与改代码；同一股票在
   2005/2015/2020/近年分段检查，上市前应无数据。历史存在示例不等于全池全历史保证。
2. 主源与不同上游对账未复权OHLC、量额与日历；先统一收盘时间/单位/盘后成交范围，
   再对差异分类。共用上游的两个API不是两份独立证据。
3. 复权按冻结因子和基准日重算，财务按公告前后及更正版查询，历史池按有效期检查。
4. 真实UI创建单标的/整池任务→Worker→非空原始批次→标准结果→质量报告→刷新图表。
   同时检查重复补缺、权限、限流、无数据、失败重试、重启及桌面/手机。
5. 连续运行记录各类覆盖、缺失、延迟、错误率、重试恢复、配额和费用；签约前核实
   允许存储/研究/应用展示的范围及支持承诺。没有连续实测就不标“已验证最稳定”。

## 多源加入方式

用户选“数据类目→来源→周期/字段→范围”，来源必须明确配置且与类目匹配。
源能力目录应分documented/configured/sample_verified/e2e_verified及blocked，提供
标的/周期实际覆盖，不以一个固定最早日期包揽全部品种。凭证使用不可公开的引用，
被冻结计划只保存非秘密授权身份及能力版本。

每个来源由自己的Adapter解释原始记录与单位，采集core只处理通用计划、归档引用、
作用域和结果，不依赖策略、交易或供应商SDK。多个来源产物并存、对账关联，缺失范围
按来源/类目/复权/时间口径计算。绝不因为主源429自动把另一源拼入同一已冻结数据集。
首轮先正式版MaiRui能力复核，再根据同一字段契约加入通过验收的主源；商业账号尚未
配置时入口禁用且明确未连接。旧数据集、策略与回测冻结引用均不改写。

## 正式证书样本与购买建议（2026-10-10）

私有配置更新后，本机与Compose的API/Worker实际进程环境均与新配置一致，未输出
凭证。以下为供应商接口探测，**不是**新的UI/Worker落库验收，也不是全市场历史保证。

| 请求 | 实际结果 | 可得结论 |
| --- | --- | --- |
| 2025日历 | HTTP200，243条日期 | 该年度日历接口可访问 |
| 600519.SH 2025-09-01～05 日线 | HTTP200，5条 | 指定样本可取，不推断全部年份 |
| 行业目录 | HTTP200，1464条 | 目录当前可访问，不等于历史成员或全部字段验收 |
| 600519.SH 2025-09-01 5/15/60分钟（lt=5） | HTTP200，分别5/5/4条 | 基础分钟接口有权限/非空；截取样本不证明全日完整 |
| 600519.SH 2015-09-07 普通5分钟（lt=5） | HTTP200，0条 | 该请求没取到记录；原因待核验，不等于全厂商无该年数据 |
| 000001.SZ 2005-01-04～06 日线 | HTTP503，来源代码503 | 暂不可用，不推断最早日期 |
| 600519.SH 2025-09-01 Pro1分钟 | HTTP403 | 本次扩展权限验证未通过，正式证书不等于已验证Pro |

因此没有理由为已有5/15/60分钟权限重复付费。若只做日频/5分钟原型，优先补齐
复权、状态与历史范围质量；若要求1分钟或多年分钟回测，则Quant Pro按月试验有
价值，但官方长历史宣称仍须以指定标的/年份的实际完整性验收。

[官方增强包](https://www.mairuiapi.com/packs)当前列出：Pro包月128元、包年888元；
新购加购页面优惠价102/月、710/年，是否适用于已有证书以实际结算为准。Pro赠送
独立因子包的同等因子权益，不建议两包重复购买。独立因子包标价68/月、488/年。
常见技术因子优先在本地由冻结数据计算；供应商财务/事件因子必须核对公式、历史
可见性、修订和版本，不能用“77因子”宣称完整研究输入。官网说明3个北向字段按
设计为空，具体策略不可默认这些字段可用。

完整历史分钟增强接口有专属域名与按年片/更新规则，现项目的普通历史Adapter
**尚未接入完整年片接口**。买权限不会自动把新类别和该接口接入项目，不承诺
购买后立刻能在当前UI下载全部年片。分钟包也不补齐2026-08-13以前的成交逐笔，
更不等同完整L2委托/撤单。

[官方套餐页](https://www.mairuiapi.com/getlicence)还披露60秒滑动窗口最多两个来源IP，
多出口可能返回429；旧测试仅观察到429，未记录足够来源代码/出口证据，不能断言
都是请求频率或日配额用完。后续限流记录须安全区分HTTP码、供应商代码与原因，
统一出口和请求节奏；Pro并非解决一切429的付费开关。

## 2026-10-18：普通历史来源标志的精确归档语义

[官方沪深接口说明](https://www.mairui.club/hsdata)对普通历史K线的`sf`定义为停牌标志，0表示正常；Pro 1分钟和完整年片必须按各自端点说明区分，不据同名字段推导同一含义。

`mairui.history-bars.v3`仅用于`mairui.history.bars`，其中普通股票历史将精确归档后的数值零文本（如`"0.0"`、`"0E-6"`）按数值零解释，避免误报可疑。原始字段保留；非零或未知仍为可疑，不用来填补缺失日，布尔、非法及非有限值拒绝转换。缺失/空标志通过`source_flag_unknown_count`记录，不默认为零。价格、成交量、单位与时间标签规则保持。[普通指数历史](https://www.mairui.club/hszsdata)不要求股票sf，按不适用处理，不把缺失误判为股票异常；指数SF两例当前为受控回归。

旧history v1/v2及Pro v1映射保持原输出，旧发布与冻结研究引用不变。Pro同名字段的逐端点政策仍属待完成质量矩阵，不把本修复写成全部行情语义已验收。由旧归档生成v3新发布时，历史截至日和原获取时刻保持，不因新发布时间宣称最新行情、PIT或研究就绪。
