# QTrade Phase 1 Backlog

> 状态说明：本文档是 Phase 1 规划过程中的背景 backlog。当前权威需求由
> `openspec/changes/add-qtrade-phase1-mvp/` 管理；两者冲突时以 OpenSpec
> proposal、spec delta、design 和 tasks 为准。

优先级定义：

- **P0**：一期 GA 必须。
- **P1**：一期目标，资源允许则交付。
- **P2**：一期可延期，但需保留架构扩展点。

## 一期裁剪顺序

如果时间不足，按以下顺序裁剪：

1. Telegram / Slack 通知，保留站内 + Email / Webhook。
2. 参数扫描与 Walk-forward，保留单次回测。
3. Tick / order book，保留 OHLCV。
4. 报告导出，保留页面报告。
5. 多市场，只保留一个市场。
6. UI 布局保存，保留基础布局。

不建议裁剪：

- SSO / 权限 / 审计。
- 数据质量。
- 回测复现性。
- 预交易风控。
- kill switch。
- 订单对账。
- 密钥加密。
- 观测与备份。
