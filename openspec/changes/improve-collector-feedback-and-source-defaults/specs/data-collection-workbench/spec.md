# Spec Delta

## Purpose

让独立采集工作台的来源默认选择符合「付费优先、免费兜底」的产品语义，并保证每一次操作的等待与失败反馈都在用户视线内、可归因，消除「点了没反应」和「不知道哪里报错」的体验断裂。

## ADDED Requirements

### Requirement: 来源默认优先可用付费源
采集创建区 MUST 在已配置（configured）且支持当前数据类别与所选周期的来源中优先选择付费（tier=paid）来源；仅当没有可用付费来源时才回退到免费来源。用户已保存偏好中的显式来源选择 MUST 不被默认逻辑覆盖。来源下拉 MUST 标注每个来源的付费/免费属性。

#### Scenario: 付费分钟源可用时选择分钟周期
- **WHEN** 目录中付费分钟来源已配置，用户把周期切换到该来源支持的分钟粒度
- **THEN** 当前来源自动切换为该付费来源，无需用户手动改选

#### Scenario: 付费源不支持日线时回退免费源
- **WHEN** 用户选择日线周期而付费来源不支持日线
- **THEN** 默认来源为支持日线的免费来源，且不出现「当前来源不支持」的悬空状态

#### Scenario: 保存偏好优先于付费默认
- **WHEN** 用户保存过显式来源选择且该来源仍可用
- **THEN** 页面恢复用户保存的来源，即使存在其他可用付费来源

### Requirement: 操作反馈就近可见且可归因
采集创建表单的失败反馈 MUST 同时出现在触发操作所在的表单页脚区域（就近内联）并可被辅助技术播报；错误出现时页面 MUST 将反馈滚动进入视口。处于等待中的操作 MUST 在对应按钮上显示进行中状态；因前置条件不满足而禁用的按钮 MUST 在按钮附近展示禁用原因。

#### Scenario: 预览失败原因出现在按钮旁
- **WHEN** 用户点击「预览独立采集计划」且上游返回超时或其他失败
- **THEN** 失败原因文案出现在表单页脚的提示区域且位于视口内，用户无需滚动到面板顶部即可归因

#### Scenario: 默认区间计算等待有反馈
- **WHEN** 用户点击「使用最近自然年日期」且计算需要数秒
- **THEN** 按钮立即显示进行中状态；成功时日期输入被填充，失败时按上一场景就近显示原因

#### Scenario: 禁用按钮说明原因
- **WHEN** 日期已填写导致「使用最近自然年日期」不可用，或来源未配置导致预览不可用
- **THEN** 按钮附近展示对应原因（已有日期需先清空 / 来源未配置），点击无效不再是无解释的沉默
