# Spec Delta

## Purpose

将股票池采集结果直接连接到市场终端，让用户以同一成员快照查看真实已发布行情、可用周期及覆盖缺口，并通过分页和明确数据状态支持完整板块而非仅少量自选。

## ADDED Requirements

### Requirement: 股票池分页市场视图
市场终端 MUST 支持按冻结股票池浏览分页成员、排序和查询覆盖，不将完整成员强塞进个人自选上限，不只扫描最近固定数量数据集。每行 MUST 展示行情日期、可用周期及覆盖状态，未接实时源时标注最近已发布行情。

#### Scenario: 成员超过个人自选上限
- **WHEN** 用户打开成员超过 50 个且所需数据集不在最近 200 个中的股票池
- **THEN** 所有成员可分页访问，旧数据仍可按标的/周期索引读取，个人自选内容保持原样

### Requirement: 采集结果行情导航
用户 MUST 能从可查看结果进入确切标的及周期的行情图；默认选择实际发布周期，无行情时 MUST 明确说明并提供预填的补缺入口，不伪造数据或误称下载失败。刷新和重开 MUST 持续访问已持久化结果。

#### Scenario: 日线任务结果打开图表
- **WHEN** 用户打开仅有日线的采集结果
- **THEN** 市场终端直接显示日线及相应覆盖，桌面和手机可操作，刷新后仍存在，无需手动切换分钟默认值

#### Scenario: 股票暂无标准行情
- **WHEN** 用户打开没有已发布行情的成员
- **THEN** 展示真实缺失或未发布状态及补缺入口，不展示其他标的或其他周期的数据

### Requirement: 比较口径可见
市场终端 MUST 仅在有实际同区间、明确行情口径的数据时启用基准比较。自编主题聚合 MUST 标注成员快照、权重公式和缺失处理，不得被命名为官方指数；未验证复权和历史成员时须保持条件可见。

#### Scenario: 指数基准来源未接入
- **WHEN** 用户打开股票池但基准指数行情不可用
- **THEN** 个股行情可查看，指数比较显示不可用，不以 ETF 或合成曲线代替官方指数

### Requirement: 聚合状态与适配布局
采集与市场页面 MUST 提供加载、空、失败及部分成功状态和键盘可操作控件，桌面/手机无无意横向溢出；聚合运行 MUST 展示数量和逐股详情，失败、无观测、未核验和可查看状态可区分，不以统一成功状态掩盖缺失。

#### Scenario: 手机查看部分完成运行
- **WHEN** 用户在手机查看含失败及已发布成员的运行
- **THEN** 能区分数量并展开单股、重试失败及进入成功图表，刷新保留最终状态
