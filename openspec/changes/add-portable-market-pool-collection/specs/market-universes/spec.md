# Spec Delta

## Purpose

提供可追溯、可冻结的自定义、指数成分、行业、市值及主题股票池，使批量采集与市场观察使用同一份成员证据，并清楚区分当前成员和已验证的历史有效成员。

## ADDED Requirements

### Requirement: 股票池成员快照
系统 MUST 返回带稳定标识、版本、观察时间、来源及成员身份的股票池快照；下载选择 MUST 冻结具体成员，成员刷新 MUST 创建新版本，不改变已提交运行或已有研究引用。跨股票池成员 MUST 按统一身份去重并保留归属。

#### Scenario: 提交后成员发生变化
- **WHEN** 用户按版本一提交采集，来源随后新增或移除成员
- **THEN** 原运行仍按版本一执行，用户可查看版本一成员，新预览展示版本二及变化

#### Scenario: 重叠主题
- **WHEN** 用户同时选择 AI 算力与芯片主题且存在相同股票
- **THEN** 采集计划只包含一个该股票身份，详情仍展示两个主题归属

### Requirement: 分类与指数身份
系统 MUST 分别展示行业、概念主题、指数及指数成分股；来源分类和映射版本 MUST 可见。股票与指数 MUST 使用无歧义身份，不得仅因数字代码相同而合并，不得用股票或 ETF 行情代替指数行情。

#### Scenario: 指数和股票同数字代码
- **WHEN** 目录含有同数字代码的指数和股票
- **THEN** 用户能区分身份与类型，指数行情任务使用已验收的指数来源，不调用股票来源冒充

### Requirement: 市值股票池口径
系统 MUST 支持按明确来源总市值或流通市值生成 Top N 快照，并显示估值日期、单位、候选市场范围、缺字段数量及筛选规则。输入不完整或口径混杂时 MUST 拒绝生成宣称完整的排名，缺值不得按零参与排序。

#### Scenario: 只有部分行情输入
- **WHEN** 候选数据只有部分股票或仅沪深但用户选择全 A 股
- **THEN** 页面说明缺失范围，完整排名入口不可用，可明确选择来源覆盖的市场后生成对应范围排名

### Requirement: 主题依据与时间有效性
系统 MUST 对 AI/芯片细分主题记录来源分类代码或有证据的人工归类规则、版本和观察日期。当前成员 MUST 标注为当前快照；没有历史有效区间证据时 MUST NOT 声称其为历史成分或真实供应商关系。

#### Scenario: 下载主题的多年历史
- **WHEN** 用户按当前主题成员下载多年行情
- **THEN** 运行保存当前成员快照，展示当前成员选择的时间口径及历史成员未核验条件，不声称历史无幸存者偏差
