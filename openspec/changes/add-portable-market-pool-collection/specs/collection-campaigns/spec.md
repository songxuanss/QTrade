# Spec Delta

## Purpose

提供从股票池选择到可查看标准行情的聚合采集流程，确保任务、原始归档、发布与质量状态真实可核对，并使数据采集可脱离策略、回测及交易项目独立运行和迁移。

## ADDED Requirements

### Requirement: 批量采集预检与冻结
系统 MUST 在批量提交前展示冻结成员、来源能力、范围、可复用/缺失部分及预计分段数量；默认日线、近一年、仅补缺，并允许修改。提交 MUST 校验权限、计划版本及来源能力，幂等持久化运行和完整待展开计划，不接受部分未校验选择。

#### Scenario: 下载整个板块或多个板块
- **WHEN** 用户从「下载全部成员」进入配置，选择当前板块或多个已保存板块并预览
- **THEN** 系统展示去重成员与七天分段数量，用户点击「一键下载所有成员」后提交冻结计划，保留多个板块归属；卡片初次点击不直接创建下载任务

#### Scenario: 计划覆盖已经变化
- **WHEN** 预览后的已有覆盖变化且原计划版本不能执行
- **THEN** 系统要求刷新计划并展示差异，不静默扩大为全量重下载，不创建部分运行

#### Scenario: 周期没有授权
- **WHEN** 用户选择当前来源未允许的分钟周期
- **THEN** 页面禁用并说明，直接请求也在提交前拒绝且没有新运行或子任务

### Requirement: 分段调度与恢复
系统 MUST 将每股合法范围按既有七天规则处理，大池可分页展开但 MUST 保存完整计划及计划/已展开计数。稳定子任务身份 MUST 保证展开重试和 Worker 重启不重复工作，成功产物不可变；失败和缺失可独立重试，来源并发和退避可配置。

#### Scenario: 子任务展开期间重启
- **WHEN** 大池只展开部分工作后服务重启
- **THEN** 系统从持久化计划继续展开，不重复已创建任务，不因部分已完成显示全池完成

#### Scenario: 部分股票失败
- **WHEN** 一部分股票已发布，一部分来源失败
- **THEN** 运行显示部分完成，用户仅重试失败或缺失范围时保留已成功批次，重下载全部为显式独立选择

### Requirement: 采集与发布结果分离
系统 MUST 分别呈现采集、标准化发布与质量核验结果，逐股及聚合显示已采集、可查看、失败和无观测数量。非空原始批次持久化且非空标准行情可查询才可显示可查看；空响应与未核验缺口 MUST NOT 被标为成功或研究就绪。

#### Scenario: Tick 已采集但尚未发布
- **WHEN** 原始 Tick 已完成归档但分钟标准数据尚未发布
- **THEN** 页面显示已采集及尚需发布条件，不标记市场分钟 K 线可查看

#### Scenario: 来源返回空响应
- **WHEN** 来源请求正常返回但没有观测记录
- **THEN** 记录无观测/待核验并保存来源事实，不以空数据集宣称可查看或完整，不自动推断停牌

### Requirement: 独立运行与受控接入
采集模块 MUST 无策略、回测、交易领域及私有数据库依赖，使用自身持久化、配置和迁移独立运行。调用方 MUST 经版本化契约和适配器访问；模块独立校验作用域与动作授权，凭证不得进入公开 DTO、事件或 UI。

#### Scenario: 移入独立部署
- **WHEN** 采集在隔离数据库与 Worker 运行且 QTrade 改用远程适配器
- **THEN** QTrade 仍能提交和查询同样结果，无跨库读取，采集不需要策略/交易库权限或用户私有会话

#### Scenario: 跨作用域或撤权请求
- **WHEN** 调用方尝试读取其他作用域结果或撤权后操作运行
- **THEN** 本地与远程适配器均拒绝，不泄露数据或创建工作，Worker 执行遵守当前来源授权

### Requirement: 发布事实可靠传播
系统 MUST 在发布产物持久化后产生可追溯版本事实，事务 outbox 保证恢复投递；消费端 MUST 去重、防版本倒退，并可通过查询和游标补拉恢复。通知不得作为唯一状态来源，缺少通知不得阻止已授权行情读取。

#### Scenario: 重复或遗漏通知
- **WHEN** 发布通知重复、乱序或暂时丢失
- **THEN** 市场视图不产生重复产物或回退，恢复后通过目录查询/补拉得到最终版本，归档及清单仍可校验

### Requirement: 稳定迁移标识
迁移 MUST 保留原始归档、产物清单、数据集及任务标识、版本和校验和，作用域映射须可审计。QTrade 历史研究引用 MUST 无需重写即可解析同一冻结产物，不得原地改写历史引用。

#### Scenario: 历史产物迁移后读取
- **WHEN** 用户读取独立部署前冻结的数据集引用
- **THEN** 返回同一身份、版本及校验和的行情和质量报告，缺少映射或产物时明确失败
