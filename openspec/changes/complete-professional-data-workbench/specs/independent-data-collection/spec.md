# 规格增量

## MODIFIED Requirements

### Requirement: 冻结来源和有界计划
模块 MUST 提供供应商无关的能力目录；计划冻结来源、类别、字段、周期、范围、转换版本和标的。按来源、类别、接口分页与配置边界拆分有界子任务，默认不限总日期范围；Pro历史分钟按年取得并截取用户范围，不再统一七天拆分；已冻结旧计划保持原样；重复数据提供补缺或全部重采，覆盖按来源及语义分别核算。

#### Scenario: 重复提交与来源切换
- **WHEN** 同一请求重试或相同范围改用另一来源
- **THEN** 前者幂等返回原任务，后者独立计划；已有来源产物不被另一来源替代，预览说明已有/缺失/处理中范围


#### Scenario: 来源感知分段与旧任务
- **WHEN** 用户创建跨年Pro分钟或长范围因子任务
- **THEN** 根据年片和因子分页限制精确规划半开范围，配置可调整且无遗漏或重叠；旧任务范围和身份不改写
