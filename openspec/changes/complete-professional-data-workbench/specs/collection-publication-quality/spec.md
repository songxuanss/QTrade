# 规格增量

## Purpose

为专业量化数据工作台提供可验证的collection-publication-quality能力，明确用户操作、版本化数据、失败恢复及研究限制，确保独立采集服务和消费者通过公开契约协作，并以真实结果区分样本、受控验证与生产可用性。

## ADDED Requirements

### Requirement: 版本化发布门禁
系统 MUST 在发布前执行版本化类别质量规则，校验格式、身份、摘要、必填、精度、单位、时区、标签、范围、重复、缺口和异常；阻断错误不得发布，可接受警告带状态发布。

#### Scenario: 阻断及修复
- **WHEN** 原始数据有阻断错误后修复转换或规则并重处理
- **THEN** 原始批次及阻断原因保留；新处理版本验证通过后发布，旧产物不改写

#### Scenario: 研究响应在解码前失败
- **WHEN** 研究来源HTTP状态拒绝、业务错误、JSON无法解码或后续转换失败
- **THEN** 已完整收到的响应字节先以私有不可变对象持久化，再登记绑定冻结请求和分片的回执；回执或索引写入失败不得继续转换或发布，HTTP 200不能作为数据有效或发布成功依据

#### Scenario: 安全只读响应回执
- **WHEN** 当前有读取权限的用户查看研究任务响应回执
- **THEN** 仅返回当前作用域和任务的有界分页元数据，按记录时间和稳定身份排序，展示状态/字节数/摘要而不返回正文、URL、头或异常字符串；历史回执不表示当前来源健康，旧任务无回执不能解释为没有采集

#### Scenario: 拒绝歧义或非有限来源JSON
- **WHEN** 行情、因子、研究或元数据来源响应含任意层级重复JSON键、非有限数值常量，或非整数业务状态码
- **THEN** 在解码前留存精确响应字节，随后以固定安全错误拒绝，不以最后一个重复值覆盖原值、不把布尔值当成功状态码、不进入转换/发布；合法有限小数保持十进制精度，已知整数权限及限流错误保持原分类

#### Scenario: 有界部分响应证据
- **WHEN** 研究HTTP传输在收到响应后截断、超过总期限或达到正文上限
- **THEN** 回收连接进程后保留已写入的有界解压字节和已知状态，以不完整回执持久化并拒绝转换/发布；超限只保留前缀且不能伪装完整，未取得任何响应的连接失败不编造HTTP回执，归档失败仍按失败结束已计费尝试

### Requirement: 类别适配与状态
规则 MUST 按类别确定严重性，不将日内有观测等同盘中完整；无停牌证据不得解释缺失为停牌或造行情。系统区分已采集、检查通过/失败、发布及消费者可见；空响应为无观测且不计价格覆盖。

#### Scenario: 空响应与缺口
- **WHEN** 来源空响应、日内缺口或稀疏财报
- **THEN** 明确无观测或按类别警告/阻断；不填造价格、不错误计满覆盖

#### Scenario: 消费者发布隔离
- **WHEN** 原始已采集但门禁未通过
- **THEN** 消费者读不到未发布记录，界面解释阻断而非下载成功

### Requirement: 不可变血缘与覆盖
系统 MUST 保存原始批次、标准记录、转换/规则版本、manifest、哈希和血缘，按来源、类别、身份、周期、调整和版本分别计算覆盖。

#### Scenario: 版本与摘要
- **WHEN** 重复读取或修订后读取冻结产物
- **THEN** 原引用内容及摘要不变，不跨来源或调整语义混算覆盖

### Requirement: 有界研究RAW离线重处理
系统 MUST 通过明确的预览/提交和独立持久任务，从已归档研究RAW执行当前注册转换及原发布门禁；不得重新调用供应商、改写原任务或改变旧研究引用。

#### Scenario: 修复转换后发布新版本
- **WHEN** 管理员确认完整RAW输入及转换版本的重处理预览
- **THEN** Worker校验输入摘要及分页完整性，在页/行/字节上限内生成带父输入血缘的新请求和发布；保留原采集时间、失败记录及旧发布引用，重复提交幂等

#### Scenario: 拒绝不完整或失效输入
- **WHEN** RAW缺页、循环、身份/摘要错误、超限、权限撤销或注册转换版本变化
- **THEN** 明确拒绝或将新任务记失败，不补造缺页、不出站补下载、不跳过门禁、不修改父任务；UI可刷新查看原因

### Requirement: 行情因子完整转换输入留存
系统 MUST 在声明支持准备输入的行情/因子Adapter执行转换前保存作用域及分段绑定的不可变检查点，包含完整RAW、原获取切片、实际日历或因子定义和数值类型、回执血缘及摘要；本地转换不得重新获取缺失上下文。

#### Scenario: 转换阻断后仍可重用原输入
- **WHEN** 时间标签或转换被拒绝后修复已注册转换器
- **THEN** 原检查点与回执保留，纯转换从冻结输入产生结果，原采集证据及旧发布不改写；准备时刻不作为PIT或来源更新证明

#### Scenario: 类型与跨年裁剪保持
- **WHEN** 因子值为精确数值、数值形文本或合法空值，或行情获取跨越年界
- **THEN** 冻结原值类型及定义，数值精度限制不放松；逐次获取按自身半开区间裁剪，不因合并RAW造成重复或扩大范围

#### Scenario: 检查点写入或完整性失败
- **WHEN** 回执/正文/身份/摘要损坏、输入超限或检查点写入失败
- **THEN** 停止转换和发布并明确失败，保留已写原始证据，不从未知输入制造完成状态

### Requirement: 明确的行情因子离线意图
系统 MUST 将用户选定的完整检查点、原获取回执摘要/时刻、当前转换/规则和上限绑定到独立不可变意图，经现有持久队列执行；公开意图不返回RAW正文或租约令牌，不重新访问供应商。

#### Scenario: 独立发布与原版本保留
- **WHEN** 当前管理员确认预览并执行离线重处理
- **THEN** 相同请求及控制摘要幂等，新任务经原质量门禁生成新发布，旧输入、失败及研究引用不变；原获取时刻和未知可知时间保持，子任务没有伪造的新HTTP获取回执

#### Scenario: 无网络回退及输入漂移拒绝
- **WHEN** 输入/回执损坏、权限撤销、转换/规则变化、当前上限收紧超限或离线元数据缺失
- **THEN** 新任务拒绝或失败，明确离线标记不得变为普通下载，也不得补抓数据或绕过门禁

#### Scenario: 离线发布的新鲜度与旧Worker安全
- **WHEN** 完整归档被重新处理并发布，或离线任务被不具备相应能力的Worker读取
- **THEN** 新鲜度追溯原输入的真实获取行及时间，不用新发布时间充当新采集；缺少证明明确不可核验。离线v2队列封套和不可变标记使旧解码器或缺失处理器拒绝，不回退出站下载

#### Scenario: 归档数值零的来源标志语义
- **WHEN** 原数值来源标志零在精确归档中表示为文本0.0，或不同端点复用相同字段名称
- **THEN** 新映射按各端点验证后的数值/领域语义处理，不把正常零误判为停牌或可疑；变更注册独立映射版本并保留旧发布，不以重写旧产物或放松新鲜度规则掩盖缺陷
