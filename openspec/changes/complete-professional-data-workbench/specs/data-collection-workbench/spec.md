# 规格增量

## Purpose

为专业量化数据工作台提供可验证的data-collection-workbench能力，明确用户操作、版本化数据、失败恢复及研究限制，确保独立采集服务和消费者通过公开契约协作，并以真实结果区分样本、受控验证与生产可用性。

## ADDED Requirements

### Requirement: 可访问的专业工作台
系统 MUST 在授权导航、直接链接、刷新及重新登录后保持工作台可访问；来源未配置、故障或无数据须显示具体状态及恢复操作，不能导致整个模块空白或循环登录。

#### Scenario: 访问与会话恢复
- **WHEN** 用户从桌面或手机主导航进入、刷新或会话过期重新登录
- **THEN** 返回工作台并显示实际来源、任务及已有数据；无权限用户仍被拒绝

#### Scenario: 来源故障
- **WHEN** 来源未配置、服务停机或上游拒绝
- **THEN** 页面保持可操作并显示相应原因，已有任务和数据仍可查询

### Requirement: 确定范围与默认值
系统 MUST 允许用户显式组合多个行业/主题/指数股票池与公司代码，合并去重后冻结输入；未选择任何池或标的时拒绝提交，不得隐式加入未选池或扩大到全市场。未设置日期默认最近自然年，结束按市场日历及来源发布时间计算；行情默认日线、仅补缺、明确调整语义，保留明确来源、周期和日期。

#### Scenario: 行业池与公司组合
- **WHEN** 用户勾选一个或多个冻结股票池，同时填写一些公司代码
- **THEN** 计划处理两者并集且去重，展示组合后标的数和来源，不忽略任何显式输入

#### Scenario: 无显式范围
- **WHEN** 用户既未勾选股票池也未填写公司代码
- **THEN** 预览被拒绝并提示先选择范围，不创建任务、不隐式扩大到全市场

#### Scenario: 日期默认与保留
- **WHEN** 用户使用默认日期或设置自定义日期
- **THEN** 展示具体半开范围、时区、默认依据；默认不以本地最后数据日期作为结束，自定义范围不被截断

#### Scenario: 不支持选择
- **WHEN** 用户切换到不支持当前周期或范围的来源
- **THEN** 保留明确选择并解释拒绝，不静默换周期或换源

### Requirement: 一键处理及可理解计划
系统 MUST 提供补齐一年、预览、执行、失败部分重试和取消；预览无副作用，显示标的、分段、覆盖、缺失和调用量。完全覆盖提示无需采集；范围扩大或达到确认阈值需确认，硬配额不得绕过。

#### Scenario: 补齐与重复点击
- **WHEN** 用户明确范围并补缺或重复点击
- **THEN** 仅创建幂等运行；全部已有不创建新下载，失败重试不重下载成功批次

#### Scenario: 预览与取消
- **WHEN** 用户查看预览或取消任务
- **THEN** 预览不创建任务；取消说明未执行、在执行和已完成部分的处置

#### Scenario: 大范围分段预估
- **WHEN** 用户选择长日期区间、多个标的或整池下载
- **THEN** 预览前按当前来源策略显示粗估分段数、每标的分段数及依据；普通分钟来源提示最多 7 天拆分并可显式切换到按日历年组织的 Pro 来源，估算明确标注以真实预览为准，不替代预览或不创建任务

### Requirement: 因子选择及结果持久化
工作台 MUST 支持分类搜索、定义查看及明确因子选择，不隐式全部下载；展示历史能力、频率、覆盖、空值与版本。日期语义明确，输入、任务与结果刷新后保持，桌面手机键盘可操作且页面无横向溢出。

#### Scenario: 所选因子历史
- **WHEN** 用户选择部分因子并指定范围
- **THEN** 仅下载所选项；仅最新值能力不伪装历史，未知元数据明确呈现

#### Scenario: 刷新与移动端
- **WHEN** 用户操作后刷新或重新打开手机页面
- **THEN** 持久输入与真实结果正确，表格局部滚动且键盘能完成主流程

### Requirement: 分区导航与有界页面
采集工作台 MUST 将行情因子、股票池、财务事件、自动更新、资产、运行监控与逐笔兼容入口分区，只展示当前分区；长记录在区域内滚动，不把所有业务表单纵向堆叠。

#### Scenario: 切换与恢复导航
- **WHEN** 用户切换分区、使用键盘、刷新或浏览器前进返回
- **THEN** 当前分区及二级选择可通过URL恢复，切换保留已填写表单与现有任务状态；旧片段链接可打开所属分区，手机导航局部滚动且页面无横向溢出

#### Scenario: 分区后的业务验证
- **WHEN** 用户从新分区执行采集或浏览已有结果
- **THEN** 仍通过当前权限、真实API/Worker/持久化及原发布门禁；未连接功能、来源错误和兼容入口保持可定位，不以页面变短隐藏失败

#### Scenario: 配置与结果分离
- **WHEN** 用户在行情与因子区新建任务、切换查看任务或重新打开任务链接
- **THEN** 新建配置与任务结果分别显示；提交成功自动显示结果，切回配置保留当前草稿，URL恢复当前视图；只读用户直接查看任务且不显示新建入口

#### Scenario: 多分段和长记录浏览
- **WHEN** 任务包含多个分段或发布记录超过一页
- **THEN** 任务选择、汇总、刷新与分页保持可达，分段和记录在有名称且可键盘操作的限高区域滚动；不裁掉记录或改变现有分页及质量/发布语义

#### Scenario: 原认证部署恢复
- **WHEN** 本机依赖容器恢复后地址变化，或原认证API/Worker退出
- **THEN** 受控恢复刷新连接并保留原身份、数据库、对象与冻结引用；仅管理已核验拥有的进程，启动配置先持久化，失败可再次恢复，不凭健康检查宣称业务完成；恢复后通过实际UI/Worker/来源/非空归档及消费者刷新验证

#### Scenario: 紧凑新建配置
- **WHEN** 授权用户在桌面或手机配置行情与因子采集
- **THEN** 常用字段集中排列，日期和下载方式保持清晰；来源和日期参考说明可按需及键盘展开，不隐藏错误、预览确认或提交，不改变输入和采集语义；使用真实下载闭环及刷新验证压缩布局没有影响功能
