# 规格增量

## ADDED Requirements

### Requirement: 并存版本及研究查询
接口 MUST 保留已有v1产物和冻结引用，研究类别通过明确并存版本发布类型化记录、时间证据、质量状态及血缘，拒绝未知版本、跨作用域、无权限和不支持的研究时点查询。

#### Scenario: 新旧产物共存
- **WHEN** 消费者读取旧行情清单或新研究类型
- **THEN** 旧清单摘要及契约不变，新类型可分页验证且只能读取通过门禁的产物；未知版本明确拒绝

#### Scenario: 终端与研究浏览
- **WHEN** 发布本次接入行情、因子、财务或事件后刷新消费者
- **THEN** 正确标的/周期/类别可见，名称、版本、单位与时间限制明确，不由旧缓存、其他标的或未发布结果伪装成功

#### Scenario: 明确消费版本的行情图表
- **WHEN** 用户从采集结果打开指定消费者数据集的图表，且同股票/周期还有另一批较近观测
- **THEN** 图表按当前作用域校验该已发布数据集、股票和周期，只读取该版本；不存在、不匹配或跨作用域时拒绝，不回退其他批次；用户可主动切换最新行情模式

#### Scenario: 研究查看者与采集创建者不同
- **WHEN** 当前具有读取权限的用户浏览另一主体采集并发布的财务或事件版本
- **THEN** 会话查询由当前查看者身份及工作区派生，不冒用任务创建者；校验返回作用域、版本、类别、游标、数量及摘要，只读角色可浏览并刷新，无权限或跨作用域仍拒绝
