# 规格增量

## Purpose

为专业量化数据工作台提供可验证的collection-freshness能力，明确用户操作、版本化数据、失败恢复及研究限制，确保独立采集服务和消费者通过公开契约协作，并以真实结果区分样本、受控验证与生产可用性。

## ADDED Requirements

### Requirement: 可解释新鲜度
系统 MUST 展示数据截至、采集、成功发布、预期更新时间及状态，按市场日历、类别及来源配置阈值，区分来源、本地采集及发布滞后。

#### Scenario: 过期归因
- **WHEN** 来源未更新、本地未采集或产物未发布
- **THEN** 分别给出滞后阶段和恢复动作，不用本地最后日期隐藏缺口

#### Scenario: 管理员按已发布证据重新核验
- **WHEN** 管理员请求重新核验某份当前作用域的未复权 A 股日线发布
- **THEN** 服务依据真实交易日历、发布时间、原始获取回执及质量重放计算并持久化快照，浏览器只能提交发布引用，不能提交作用域、健康状态或检查时间；只读角色和缺少 CSRF 的会话变更请求被拒绝

#### Scenario: 当日数据与缓存不能伪造完整周期
- **WHEN** 记录属于当日但获取早于实际预计发布时间，或获取回执仅证明缓存重读
- **THEN** 不将该记录认证为完整周期；必须证明所选原始行在对应发布时间后真实取得，时间边界保留日期及市场时区

#### Scenario: 旧历史重新核验
- **WHEN** 用户对旧历史归档重新核验但没有来源最新周期观测
- **THEN** 预期时间来自当前来源规则，旧行情仍不能证明今日来源可用；快照读取与重新核验操作明确区分，重新核验不隐式下载最新行情

### Requirement: 告警与恢复
过期 MUST 进入运维健康及既有项目告警链路，重复告警去重，恢复保留轨迹；外部不可用不能伪装新鲜。

#### Scenario: 过期恢复
- **WHEN** 同一对象持续过期后恢复发布
- **THEN** 产生去重告警和可追溯恢复事件，不反复新建重复告警

#### Scenario: 核验与待投递事实原子保存
- **WHEN** 已授权的当前核验进入过期或来源不可用状态
- **THEN** 核验快照和不可变待投递事件在同一事务保存；事件写入失败则两者回滚，相同异常持续核验不重复开启事件，精确历史归档不产生运维告警

#### Scenario: 未知不等于恢复
- **WHEN** 异常期间插入未知、宽限或来源状态未知的已覆盖发布记录
- **THEN** 保留同一异常事件，不把这些记录当作恢复；只有当前预期周期已发布且来源可用才追加关联恢复事件，再次异常具有新的事件身份

#### Scenario: 有序租约与重放
- **WHEN** 消费者重启、确认失败或租约过期重领
- **THEN** 同数据口径的恢复事件不得越过未确认的开启事件；旧令牌不可确认新租约，告警与通知使用稳定身份幂等，持久接收后才确认

#### Scenario: 投递当前授权
- **WHEN** 原操作主体权限被撤销或消费者/作用域/令牌不匹配
- **THEN** 不接受确认或绕过当前权限；原不可变事实保留，不能把领取或排队记录称为通知送达

### Requirement: 显式持久后台核验
系统 MUST 保存按完整数据口径区分的后台核验配置、当前授权主体、周期、启停、应执行时间和版本，默认停用；明确启用后遵守现有来源预算，不隐式下载行情。

#### Scenario: 停用、撤权与重启
- **WHEN** 核验执行中配置被停用、主体被撤权或进程重启
- **THEN** 旧租约不能在停用确认后提交新快照或事件；撤权暂停，持久配置与已完成结果保留，到期可重领且通知保持幂等

#### Scenario: 较新失败覆盖旧健康
- **WHEN** 较新的后台核验失败，但上次健康快照尚未超过年龄有效时长
- **THEN** 当前展示为待核验，保留历史证据；配置修改不抹掉失败时点，较新成功检查可取代较旧失败

### Requirement: 有界只读健康总览
系统 MUST 通过共享公开契约展示当前作用域已有核验或后台配置的数据口径，使用有界游标分页；读取不触发来源请求、核验、下载或事件领取。未列出不代表健康，配置存在不代表授权或来源连接已验证。

#### Scenario: 已保存检查的当前有效性
- **WHEN** 已保存检查超出有效时长、存在较新失败、检查时钟异常或来源版本未注册/配置
- **THEN** 不展示为当前健康，保留历史证据及明确原因；浏览器按单调时间老化，读取失败后旧记录仅供参考，重试可恢复

#### Scenario: 分页与权限隔离
- **WHEN** 当前具有读取权限的用户浏览或刷新健康总览
- **THEN** 服务只返回当前作用域按完整口径摘要排序的一页记录，限制每页最多100项；会话桥接推导主体及作用域，拒绝非法游标、跨域与匿名请求，不因分页改变核验或投递状态

#### Scenario: 事件接收不等于最终通知送达
- **WHEN** 健康记录关联已领取、租约到期或消费端已确认的事件
- **THEN** 展示对应接收状态和告警入口，明确确认仅代表持久接收，不推断最终通知渠道已送达
