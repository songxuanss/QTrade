# 提案

## Why

现有独立采集已具有真实分钟/短期因子下载，但主部署入口缺少身份配置，且默认一年、一键处理、自动增量、发布门禁、新鲜度、用量与研究类别生命周期尚不完整。用户已启用 `docs/goals/data-collection-professional-workbench.md` 的全部目标，需逐项以真实部署结果交付，不能由任务勾选或供应商文档代替。

## What Changes

- 先复现并修复已公布 13000 入口；保留原持久业务数据与角色权限，明确 Web/SSO/API/独立采集/消费者的真实部署关系。已有修复与证据由 `extract-independent-data-collection` 的新增 4.3 记录。
- 已运行当前证书下的行情、因子、财务三表、公告、分红、复权价格、当前成员及退市标的有界探查。继续核对历史范围、单位、累计/单季、因子公式异常、修订及复权基准，已依据第二轮有界证据固定 docs/data/COLLECTION-ACCEPTANCE-SCOPE.md 接入/验收清单，不为通过验收删减已固定项。
- 行情与用户选择的历史因子作为必交付；纳入已验证的普通历史财务和分红送转有限语义，保留原值、原单位、日期、修订未知和研究限制。PIT、历史有效成员、退市/身份变更、完整公司行为及复权因子无法确认时提供实际可用的类型化扩展契约、能力状态与明确拒绝；未知能力不等于这些数据已经可用。
- 工作台形成选择→预览→执行→结果；行情默认日线、最近自然年、仅补缺，保留明确日期/周期/来源。支持所选标的优先、冻结池成员、一键补齐一年、失败部分重试、取消、输入/进度持久化、桌面手机与键盘操作。
- 来源感知且可配置的分段/分页/缓存/重试，替代统一七天原子范围要求；旧计划与产物不重写。新增版本化质量门禁，保存阻断批次及原因，检查通过/警告可发布后再由消费者展示。
- 新增持久日频及类别适配调度、当前授权回查、交易日历、停机有界补跑、幂等身份与有界修订复核；不把季度财报或稀疏事件套用价格日完整性规则。
- 显示来源、本地及发布滞后、截至/采集/发布/预期时间；新鲜度过期和恢复进入既有告警链路并去重。预览与执行共享来源/作用域用量、并发、每日预算、单次规模和公平领取控制，显示估计与实际调用、重试、等待和存储。
- 通过公开版本化接口承载新类型的发现、计划、原始归档、标准化、质量、发布与查询。受控 Adapter 验证未知可知时间、版本迁移、成员区间及事件去重；fixtures 明确不计供应商实接。
- 完成真实主干/UI验收、主业务覆盖矩阵、小中大基线和复测、隔离备份恢复、配置/运维/扩展说明与可复核证据。

## Capabilities

### New Capabilities

- `data-collection-workbench`: 范围、默认值、因子选择、一键处理、执行与结果及访问可靠性；沿用前一 UI 活动变更的同名能力，扩充业务行为而不重复宣称已交付。
- `research-record-lifecycle`: 来源证据目录、类型化研究数据、时间/修订/单位语义及经过验证的扩展生命周期。
- `collection-scheduling`: 授权调度、市场/类别更新规则、增量、停机补跑和修订复核。
- `collection-publication-quality`: 类别适配、版本化门禁、阻断原始留存、重新处理与可发布状态。
- `collection-freshness`: 预期更新、滞后归因、健康视图及告警/恢复。
- `collection-usage`: 调用成本、来源/作用域预算和并发、规模拒绝、公平性及运维指标。

### Modified Capabilities

- `independent-data-collection`: 来源感知分段、共享手工/定时执行控制与扩展类别，保留独立部署和权限隔离。
- `data-publication-interface`: 并存版本、新类型/质量/时间证据、只发布合格产物及明确版本/研究时点查询。

## Impact

独立 data-contracts/core/Provider/PG/archive/HTTP、collector 调度和质量执行；QTrade 仅通过公开契约适配身份、行情/因子/财务/事件消费与告警；工作台、部署脚本、运维和测试。既有 v1 清单与冻结研究引用不变，新类型通过明确的新版本并存，不静默改变已有价格语义。

目标台账 `docs/testing/COLLECTION-GOAL-COVERAGE.md` 保留全部原要求。现有其他活动变更仍保留未完成项；本变更不把尚无账号的 RQData/Tushare 或完整交易链路计为完成。

## Non-goals and Safety Boundaries

不新增采购、新厂商账号或实盘订单；不删除生产数据、不在生产执行恢复、不以 fixture/queued/健康检查替代真实闭环。不宣称所有供应商、全市场全历史、完整跨来源 PIT/历史证券库/L2/低延迟交易体系，也不重算所有供应商因子；数据能力不足须显示限制，不能从采集完成自动推出回测/研究就绪。

## Unresolved Material Assumptions

来源真实元数据缺 unit/update_freq/calc_version；早年历史 PE 为负及 ROE 偏高待交叉核对，因子准确性不成立。财务数值单位、累计/单季、历史区间与原始修订账本尚未完全证实，普通历史接入保留未知及原值，不作转换承诺；仅披露日期不能证明 PIT。当前成分无历史有效区间，退市单样本 404 不等于供应商不提供；复权价格不等于已取得因子/基准。账户实际配额与存储/展示许可未形成完整证据，先使用保守可配置预算，记录解阻条件。跨物理机器尚无环境，以当前真实部署验收并明确该限制。
