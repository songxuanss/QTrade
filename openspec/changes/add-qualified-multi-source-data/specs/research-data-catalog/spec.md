# Spec Delta

## Purpose

建立A股量化研究数据的类别、字段、单位和历史可见性标准，令使用者知道所下载记录表达的市场事实及适用范围，并可在多源切换时验证同类数据的实际可比性。

## ADDED Requirements

### Requirement: 类目与字段口径可查询
系统 MUST 区分证券参考/交易状态、价格Bar、复权公司行为、历史成分、估值、财务、行情快照、成交逐笔、委托逐笔和事件数据；每类公开字段定义、单位、必需性、缺失语义、时间及质量条件，未实现类别明确不可下载。

#### Scenario: 相同频率但不同市场事实
- **WHEN** 用户查看秒级行情快照与成交逐笔的字段
- **THEN** 系统分别说明累计量额/盘口与单笔量额/成交身份，不将快照或分钟数据标为完整逐笔

### Requirement: 原始值与标准转换可追溯
系统 MUST 保留原始记录及来源、字段映射版本、单位转换和产物引用。相同类目输出使用明确时区、时间精度、量额单位与价格口径；未知值不能伪造为零。

#### Scenario: 两来源量额单位不同
- **WHEN** 一来源按手/千元返回，另一来源按股/元返回
- **THEN** 标准结果使用声明的统一单位，原值与转换版本可核验，单位未知的记录不能被标为已核验

### Requirement: 历史可见性与修订保留
财务、事件和历史成分 MUST 声明有效时间、公开可知时间及修订证据；缺少历史可见性时明确限制，不用当前值回填过去，不把报告期结束当公开日期。

#### Scenario: 财报晚发布并随后更正
- **WHEN** 报告期已结束但尚未公告，或用户查询更正前的时点
- **THEN** 查询仅使用该时点已可知版本，无法证明时明确未验证，不返回未来财报或更正值作当时事实

### Requirement: 复权与可成交价格分离
系统 MUST 将未复权价格、复权因子及公司行为分别标识；派生复权结果携带算法、因子版本与基准日，不能代替真实成交价格或覆盖既有不可变结果。

#### Scenario: 更换复权基准日
- **WHEN** 用户使用相同原始价格和不同复权基准重新计算
- **THEN** 系统产生可区分版本，保留原引用及计算依据，不改写冻结研究输入
