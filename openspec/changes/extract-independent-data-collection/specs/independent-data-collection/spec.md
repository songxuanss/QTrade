# 独立采集规约

## Purpose

采集模块可在没有QTrade策略、账户数据库和业务Worker的机器上独立运行。调用方通过受控接口指定来源、股票或股票池与日期范围，获得可恢复进度、真实非空归档或明确异常证据，支持将来替换数据供应商。

## ADDED Requirements

### Requirement: 实际部署入口可访问
Web 部署 MUST 显式接入真实身份配置与认证 API。授权用户可从主导航或直接 URL 进入采集工作台、刷新及会话过期后重新认证返回；采集服务故障时保留可访问工作台及具体不可用状态。开发验收入口的通过不能替代已公布部署入口的验收。

#### Scenario: 已公布入口缺少身份配置
- **WHEN** 主 Web 部署未传入身份设置而登录返回 503
- **THEN** 部署修复配置传递和可达连接，保留鉴权，必须在该入口通过真实登录、持久化采集、刷新和角色检查才声明恢复

#### Scenario: 独立采集服务停止
- **WHEN** 独立采集服务暂不可用
- **THEN** 授权用户仍能打开工作台，看到具体连接异常和已有兼容任务，不能创建虚假采集任务

### Requirement: 独立运行与权限隔离
模块 MUST 独立安装部署，拥有自己的任务存储和归档，不导入QTrade业务代码或访问其私有表。远程调用须认证服务身份并校验主体、作用域和操作权限；后台执行前重新校验权限。

#### Scenario: 采集服务部署在不同网络
- **WHEN** QTrade通过配置地址连接单独部署的采集服务
- **THEN** 下载和查询均通过公开接口完成，采集服务不需要QTrade业务库凭证；无有效授权、跨作用域和只读提交被拒绝

### Requirement: 冻结来源和有界计划
模块 MUST 提供供应商无关的能力目录；计划冻结来源、类别、字段、周期、范围、转换版本和标的。超过七天按有界子任务执行，默认不限总日期范围；重复数据提供补缺或全部重采，覆盖按来源及语义分别核算。

#### Scenario: 重复提交与来源切换
- **WHEN** 同一请求重试或相同范围改用另一来源
- **THEN** 前者幂等返回原任务，后者独立计划；已有来源产物不被另一来源替代，预览说明已有/缺失/处理中范围

### Requirement: 真实归档与恢复
完成 MUST 以经过摘要验证的非空原始批次和适当标准记录为依据。租约过期、进程重启、限流和超时须可恢复；无记录、空字段、部分失败与完成分别表达。

#### Scenario: 来源为空或进程中断
- **WHEN** 返回空数据或持久化后进程中断
- **THEN** 空数据不标下载成功；重启恢复子任务且不重复写入产物，错误类别和下次重试时间可查询

### Requirement: Pro分钟与因子适配
已配置来源 MUST 支持声明的分钟周期和因子目录/历史序列，年片按年请求并复用，当前年按公开更新规则处理。字段目录动态保存版本，空值不伪造零，缺少历史可见证据的因子不能宣称PIT回测就绪。

#### Scenario: 因子目录与权限变化
- **WHEN** 来源新增因子、某字段设计为空或订阅拒绝
- **THEN** 显示实际元数据和状态，原版本保留；实际拒绝明确阻塞，不由配置开关伪造已获得权限

### Requirement: 结构化可定位日志
模块 MUST 输出关联请求、任务、子任务、来源、尝试次数、阶段、耗时和安全错误码的结构化日志，支持配置日志级别及容器轮转；凭证、授权头、带秘密URL和原始上游错误不得进入日志。

#### Scenario: 调查下载失败
- **WHEN** 运维按界面关联ID检索日志
- **THEN** 可定位预检、请求、归档或转换阶段和重试状态，日志及报告中均无供应商凭证
